# 总结对话为学习笔记

## 概述
此 Skill 用于将当前的 AI 对话总结为一份结构化的 Markdown 文档，包含关键操作步骤、代码示例、学习要点，方便日后参考和学习。

## 适用场景
- 完成一个技术任务后，想要记录学到的知识
- 解决了一个复杂问题，想要保存解决方案
- 学习了新的技术或工具，想要整理笔记
- 想要分享经验给其他人

## 输出文档结构

生成的 Markdown 文档应包含以下部分：

### 1. 标题和元信息
```markdown
# [主题标题]

**日期**: YYYY-MM-DD
**标签**: #标签1 #标签2 #标签3
**难度**: 初级 / 中级 / 高级
**预计阅读时间**: X 分钟

## 📋 概述
简要描述本次对话解决的问题或学习的内容。
```

### 2. 目标和背景
```markdown
## 🎯 目标
- 目标 1
- 目标 2
- 目标 3

## 📖 背景知识
描述相关的背景知识或前置条件。
```

### 3. 详细步骤
```markdown
## 🔧 操作步骤

### 步骤 1: [步骤标题]

**说明**: 描述这一步要做什么

**代码**:
\`\`\`powershell
# 具体的命令或代码
command --option value
\`\`\`

**预期输出**:
\`\`\`
输出示例
\`\`\`

**注意事项**:
- 注意点 1
- 注意点 2
```

### 4. 关键代码汇总
```markdown
## 💻 关键代码

### 完整脚本
\`\`\`powershell
# 脚本名称: script-name.ps1
# 功能描述: 描述脚本功能

# 代码内容
\`\`\`

### 常用命令速查
| 命令 | 说明 | 示例 |
|------|------|------|
| cmd1 | 说明1 | `cmd1 arg` |
| cmd2 | 说明2 | `cmd2 arg` |
```

### 5. 学习要点
```markdown
## 📚 学习要点

### 核心概念
- **概念1**: 解释
- **概念2**: 解释

### 最佳实践
1. 实践 1
2. 实践 2

### 常见错误和解决方案
| 错误 | 原因 | 解决方案 |
|------|------|----------|
| 错误1 | 原因1 | 解决方案1 |
```

### 6. 总结和扩展
```markdown
## ✅ 总结
总结本次对话的主要收获。

## 🔗 相关资源
- [资源名称](URL)
- [文档链接](URL)

## 📝 后续计划
- [ ] 待办事项 1
- [ ] 待办事项 2
```

## 文件保存位置

建议的保存位置：
- **项目相关**: `<项目目录>/docs/notes/` 或 `<项目目录>/user_data/notes/`
- **通用学习笔记**: `~/Documents/LearningNotes/` 或自定义位置

## 文件命名规范

推荐格式: `YYYY-MM-DD_主题关键词.md`

示例:
- `2026-02-05_git-sync-upstream.md`
- `2026-02-05_freqtrade-backtest-analysis.md`
- `2026-02-05_powershell-automation.md`

## 使用提示

1. **在对话结束前**请求总结，这样可以包含完整的上下文
2. **指定保存位置**，告诉 AI 你希望文件保存在哪里
3. **指定重点**，如果只想记录某些方面，可以明确说明
4. **请求格式调整**，如需要更简洁或更详细的格式

## 示例请求

```
请帮我总结这次对话，生成一份学习笔记：
- 保存到: ./docs/notes/
- 重点: Git 操作和命令
- 格式: 包含步骤说明和代码示例
```
